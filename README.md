# E-commerce Sales Analysis with Python & Pandas

## 📊 About the Project
This is one of my first practical projects in Data Analysis. It explores an e-commerce sales dataset using Python and Pandas to practice basic data analysis skills.

## 🎯 Project Goals
- Explore and understand the dataset.
- Analyze sales by city and product.
- Identify the highest sales values.
- Handle missing values.
- Create new columns, including discounted prices.

## 🛠️ Tools Used
- Python
- Pandas
- Jupyter Notebook

## 📁 Dataset
The dataset contains 120 sales orders and includes information such as customer age, city, product, price, quantity, payment method, rating, and total sales.

## 📈 Key Findings
- Highest individual order value: **7,246.50**
- Most-sold product by quantity: **Monitor (63 units)**
- City with the highest average sales: **Abha**

## 📚 What I Practiced
- Data exploration and filtering
- Using `groupby()` to summarize data
- Handling missing values with `isnull()` and `fillna()`
- Creating new columns with Pandas
